# Локальное подключение ADS

Проект использует source-linked подключение к `~/ai-develop-system`.
В корне checkout выполните:

```sh
python3 -B ~/ai-develop-system/bin/ads.py --project "$PWD" install
python3 -B ~/ai-develop-system/bin/ads.py --project "$PWD" install --apply
python3 -B ~/ai-develop-system/bin/ads.py --project "$PWD" init
python3 -B ~/ai-develop-system/bin/ads.py --project "$PWD" doctor
```

Первый вызов показывает план, второй создаёт ссылки на скиллы, копии ролей,
локальный `AGENTS.md` и определения хуков. Доверие проекту и хукам проверяется
отдельно в Codex; установка сама по себе не доказывает их активацию.

Машинные пути, manifest установки и рабочая память `.ai/` исключены из Git.
Исходники ADS должны оставаться доступны. Итоговые изменения продукта и их
проверки описываются в переносимой документации проекта.

Для текущего аудита выбраны завершение `local`, ветки `typed` и отдельный
ревьюер `agent`. Push выполняется по прямому поручению пользователя.
Подтверждения этапов опираются на его явное указание считать изменения ADS
подтверждёнными; это не интерактивное согласование каждого пакета.

Снятие подключения: сначала `remove` для просмотра, затем `remove --apply`
тем же CLI. Память `.ai/` сохраняется. Подробности и ограничения —
`~/ai-develop-system/docs/installation.md`.
